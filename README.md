# Sprint-7
Análisis ConnectaTel

El objetivo del proyecto, Este proyecto tiene como objetivo analizar el comportamiento de los clientes para el conocimiento y maximización de estrategias de marketing detectando dónde existen comportamientos atípicos y usar segmentacion de clientes. Para este proyecto se utilizan tres diferentes datasets:
plans.csv → información de los planes actuales (precio, minutos incluidos, GB incluidos, costo por extra)
users.csv → información de los clientes (edad, ciudad, fecha de registro, plan, churn)
usage.csv → detalle del uso real de los servicios (llamadas y mensajes)
En los que primero se analiza y limpia la información, se segmenta y después se crean perfiles estadísticos de los clientes, en los cuales se concluye con identificar patrones, se recomiendan estrategias y mejoras en los planes.
